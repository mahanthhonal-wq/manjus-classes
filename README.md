# Manju's Classes website

A responsive, interactive single-page website for Manju's Classes in Mysuru.

## Interactions

- Learning mode tabs switch between classroom, live online and placement summaries.
- Programme filters and search narrow the course cards.
- Exam search filters the exam list.
- Student results and learner testimonials have accessible previous and next controls.
- Enquiry form prepares a message in WhatsApp; it does not store form data.
- FAQs expand natively, counters animate when visible, mobile navigation opens and closes, and scroll progress follows the page.
- Reduced-motion preferences are respected.

## Publish with GitHub Pages

The workflow in `.github/workflows/deploy.yml` deploys the repository root whenever a change is pushed to `main`. The repository's Pages source should be set to GitHub Actions.

## Branding and imagery

The supplied Manju's Classes logo is used throughout. Campus photographs are intentionally omitted until approved classroom and building images are provided.

## Content

Institution information, course categories, claims, contact details and student milestones were adapted from the current public Manju's Classes website. Batch availability, fees and schedules should be confirmed with the centre.
